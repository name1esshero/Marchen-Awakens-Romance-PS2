delegated workers. Keep them separate from active assignments and broad
workstreams; count only bounded, independent jobs with explicit scope,
exclusions, evidence inputs, output, and completion gate. This is a 2:1
ready-task-to-authorized-worker reserve, not a promise to manufacture work when
the dependency graph does not support it.

contribute bounded work from the code frontier. Every card identifies its lead
and domain. The queue coordinator checks dependencies and active scopes before
marking a contribution `READY`; reserve ratios are tracked separately for each
authorized worker pool.
